# Dita 15 — Weather API

Projekti kërkon lokacionin me `expo-location`, përdor `fetch` për Open-Meteo dhe ruan përgjigjen me `useState`. `async/await` pret operacionet asinkrone; `try/catch` trajton gabimet.

## Ushtrimi
Shfaq koordinatat dhe shto mesazh tjetër kur temperatura është nën 10°C. Nisja: `npm start`.
